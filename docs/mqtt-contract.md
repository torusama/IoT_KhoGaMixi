# MQTT Communication Contract

This document is a placeholder for the future MQTT communication contract.

The following items will be defined during the communication design phase:

- MQTT topic names and topic hierarchy.
- Payload schemas and data types.
- Quality of Service (QoS) requirements.
- Retained-message behavior.
- Device command and command-acknowledgment rules.
- Error and validation behavior.

No topics, payload schemas, or acknowledgment rules have been finalized.
