# Frontend

Bản thử nghiệm Node-RED Dashboard 2.0 nằm trong [dashboard](dashboard/README.md). Demo chạy độc lập và được đánh dấu rõ; tích hợp production với backend REST/SSE, geometry F02.1 và thống kê F04 chưa hoàn thành. `assets/js/posture-api.js` là client REST/SSE có sẵn. Xem [API](../docs/api.md) cho contract và trạng thái lệnh.
