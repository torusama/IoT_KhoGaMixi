# Frontend

Dashboard hoàn chỉnh chưa được xây dựng. `assets/js/posture-api.js` là ES module dùng được với frontend riêng hoặc widget: REST commands/history/report và fetch SSE có Bearer header.

Xem [API](../docs/api.md) cho schema, cursor, trạng thái applied/unknown, lưu final và xử lý reconnect. Client không tự cộng histogram hoặc dựng mô hình từ sensor lỗi.
